# BLE Chinese API v0.6.7-debug 测试说明

这个压缩包用于测试 BLE 中文 API 最小诊断示例 App。

## 包内文件

- `sample_app-v0.6.7-debug.apk.1`
- `README.md`

如果手机不能直接安装 `.apk.1`，请先把文件名改为：

```text
sample_app-v0.6.7-debug.apk
```

## 测试重点

1. 两台 Android 设备都安装 `v0.6.7-debug`。
2. 两台设备都允许蓝牙、附近设备和定位相关权限。
3. 两台设备都点击“启动通信”。
4. 等待界面出现 `ready=1` 或“对手就绪：1/1”后，点击“短测”。
5. 测试一台设备点击“停止通信”，另一台设备应进入不可发送状态。
6. 再手动点击“启动通信”，确认两台设备可以重新连接并继续收发。
7. 测试完成后点击“保存日记”，把生成的 txt 日志发回用于分析。

## 预期结果

- 正常连接后可以双向发送短消息。
- 对端停止通信后，本机不应继续把对端显示为可发送。
- 停止通信后旧 BLE 回调不会恢复旧连接状态。
- 手动重新启动通信后，可以恢复连接和发送。
- “保存日记”会生成 UTF-8 文本日志，Android 10 及以上通常保存在系统 Downloads 目录。

## 注意事项

- 不同 Android 厂商的蓝牙权限入口可能不同，请确认蓝牙已开启。
- 如果系统要求定位权限或定位服务，请允许并开启。
- 当前测试包用于验证 BLE 通信链路和诊断日志，不包含具体业务界面。
